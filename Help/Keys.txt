Global:

Ctrl+Return runs the full query.
Shift+Return runs the statement at the cursor.
Tab switches between the main area and the query list.
Escape restores saved focus or closes the active panel.

Main area:

K opens Stop/Kill options for the running query.
R runs the query.
X runs the current statement.
E edits an executed query.
F searches results.
O exports results.
S toggles status information.
P toggles temporary fast preview.
Q toggles query-editor visibility above results.
N toggles temporary result row numbers.
1-9 switches the active statement or result.

Query list:

Insert creates a query.
Delete deletes a query.
Return renames a query.
Space pins or unpins a query.

Read-only query view:

V returns to the result view.

Result table:

Return updates the selected row.
Insert inserts a row.
Delete deletes selected rows.
Space opens the selected field value.

Panels and controls:

Return accepts the focused action.
Escape cancels or closes.
Arrow keys move in lists, tables, editors, and tab strips.
