The result area shows the output of the active query: tables, messages, status information, or the read-only query text that produced the result.

Table results support navigation, search, fast field preview, and row numbers.

MongoDB find and read aggregate commands are converted to table results so documents can be browsed like rows. The full document remains available from MongoDB document actions where supported.

Row-level operations generate SQL or MongoDB commands from the selected rows and current table or collection context. Review generated insert, update, and delete statements or commands before running them.

MongoDB write and index command replies are shown as JSON status text when the command returns a single result document.

Export writes result data to file or clipboard formats for reuse outside MADB.

When multiple statements produce results, number keys switch between them.
