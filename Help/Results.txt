The result area shows the output of the active query: tables, messages, status information, or the read-only SQL that produced the result.

Table results support navigation, search, fast field preview, and row numbers.

Row-level operations generate SQL from the selected rows and current table context. Review generated insert, update, and delete statements before running them.

Export writes result data to file or clipboard formats for reuse outside MADB.

When multiple statements produce results, number keys switch between them.
