The current schema is the default database context for table menus, query templates, generated SQL, and result row operations.

The Schema menu works with schemas on the active connection. Use schema operations carefully, especially when renaming, copying, or dropping database objects.

The Table menu works inside the current schema. It is the starting point for browsing table data, inspecting definitions, editing structures, copying objects, and creating row-change SQL.

Table editors and row actions generate SQL first. Use that preview as the safety step before running structural or data changes.
